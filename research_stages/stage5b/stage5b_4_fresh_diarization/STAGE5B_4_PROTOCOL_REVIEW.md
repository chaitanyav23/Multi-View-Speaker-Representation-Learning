## 1. Executive Summary & Experimental Objectives

Stage 5B.4 represents the integration phase of the Stage 5B research trajectory. Up to this point, improvements in Voice Activity Detection (VAD) from Stage 5B.1, Multi-Speaker Overlap Attribution from Stage 5B.2, and Speaker Count Estimation from Stage 5B.3 were evaluated primarily through **transductive projection** or modular evaluation on frozen subsegments. Specifically:
- Stage 5B.1 evaluated VAD operating points by projecting frozen Stage 5A Condition J speaker labels onto candidate VAD speech intervals via nearest-neighbor interpolation (`project_vad_to_diarization_audited`).
- Stage 5B.2 evaluated overlap detection and attribution methods on top of those projected VAD RTTMs.
- Stage 5B.3 evaluated eigengap heuristics and spectral clustering tuning on precomputed Stage 3 affinity matrices.

The objective of **Stage 5B.4 (Fresh Diarization Evaluation)** is to test whether the upstream VAD and downstream overlap gains survive **end-to-end re-clustering**, where:
1. Candidate VAD boundaries define the speech segments.
2. Fresh multi-scale subsegments are generated strictly within those speech segments.
3. Dual-encoder representations (NVIDIA TitaNet-Large and WeSpeaker VoxCeleb ResNet293-LM) are extracted on those exact subsegments.
4. Multi-scale cosine affinity matrices are computed and normalized via off-diagonal z-scoring.
5. Unsupervised equal-weight fusion (Condition J) is performed.
6. Fresh Normalized Maximum Eigengap Spectral Clustering (NME-SC) assigns speaker labels to subsegments without any knowledge or leakage of prior cluster labels.
7. Overlap handling (either single-label baseline or conservative multi-speaker attribution) is applied to the fresh single-speaker hypothesis.
8. Downstream diarization and conversational ASR (cpWER) metrics are calculated.

### 3.2 Overlap Configurations & Disambiguation

A critical finding of this audit is a **nomenclature collision** between Stage 5B.2 and Stage 5B.4:

> [!WARNING]
> **Nomenclature Disambiguation Required:**
> - In **Stage 5B.2**, conditions were numbered `O00` through `O44`. There, `O00` represented `C00 x M0_no_overlap`, `O01` represented `C50 x M0_no_overlap`, and `O02` represented `C62 x M0_no_overlap`.
> - In **Stage 5B.4**, the protocol uses `O02` to generically denote the **`M0_no_overlap` single-label baseline** across *all* VAD conditions (`E00: C00 x O02`, `E10: C50 x O02`, `E20: C62 x O02`).
> - To avoid catastrophic script lookup errors, any Stage 5B.4 implementation script must explicitly bind each condition to the semantic method name (`M0_no_overlap` vs `M4_conservative_abstention`) rather than relying on the Stage 5B.2 condition ID `O02`.

#### The Two Overlap Methods:
1. **`M0_no_overlap` (`O02` in Stage 5B.4)**:
   - Preserves single-label diarization hypothesis directly from clustering.
   - Any detected overlap intervals remain assigned exclusively to the primary speaker.
   - No secondary speaker segments are inserted into the RTTM.
2. **`M4_conservative_abstention` (`O42-R2` in Stage 5B.4)**:
   - Operates on the single-speaker hypothesis RTTM and raw 16k mono overlap posteriors ($p_{\text{ovl}}$).
   - Overlap candidate detection threshold: $\tau_{\text{ovl}} = 0.40$ on `p_overlap` from Pyannote mono posteriors.
   - Minimum overlap duration: $\ge 0.10$s.
   - Contiguous turn search: Searches backward from overlap start for preceding speaker turn ($\ge 0.20$s) and forward from overlap end for subsequent speaker turn ($\ge 0.20$s) within a 5.0s window (`extract_contiguous_turns`).
   - Attribution rule:
     - If preceding turn speaker $\neq$ subsequent turn speaker, and one matches the primary speaker, the other speaker is attributed as the secondary speaker.
     - If preceding and subsequent turns belong to the same speaker, or if no valid adjacent speaker is found, the system **abstains** (leaves the interval single-speaker) to prevent false-alarm speaker assignment.

## 4. Compatibility Analysis: O42-R2 with Fresh Diarization

A central question for this audit is whether `O42-R2` is dependent on frozen Stage 5A Condition J labels or can operate dynamically on fresh single-speaker diarization hypotheses.

### Forensic Finding:
Audit of `research_stages/stage5b/stage5b_2_overlap_optimization/audit_corrections_v4_1/scripts/run_stage5b_2_corrected_v4_1.py` lines 671–760 and 917–926 reveals:
```python
def attribute_m3_m4_corrected(
    frame_spk: List[Optional[str]],
    overlap_interval: Tuple[float, float],
    primary_spk: Optional[str],
    method: str = "M4",
    resolution: float = 0.01,
    max_gap_sec: float = 5.0,
    min_turn_dur_sec: float = 0.20,
) -> Dict[str, Any]: ...
```

**Classification**: **`O42-R2` is FULLY COMPATIBLE with fresh diarization via adapter**.
- It does **not** consume speaker embeddings, cluster centroids, or ground-truth speaker mappings.
- It takes as input only the rasterized `frame_spk` representation of the input single-speaker hypothesis RTTM.
- The speaker labels within `frame_spk` are treated as arbitrary categorical identifiers (e.g., `speaker_0`, `speaker_1`).
- Therefore, when fresh NME-SC clustering outputs arbitrary cluster labels, `attribute_m3_m4_corrected` will operate correctly and deterministically on those fresh labels without any code modification.

## 5. Factorial Analysis Plan & Statistical Rigor

The $3 \times 2$ factorial structure permits exact decomposition of diarization variance:

$$\text{Metric} = \mu + \alpha_{\text{VAD}} + \beta_{\text{Overlap}} + (\alpha\beta)_{\text{VAD}\times\text{Overlap}} + \epsilon$$

1. **Main Effect of VAD**:
   - $E10 - E00$: Impact of raw mono VAD vs DFN baseline under single-label diarization.
   - $E20 - E00$: Impact of consensus VAD vs DFN baseline under single-label diarization.
2. **Main Effect of Overlap**:
   - $E01 - E00$: Impact of conservative overlap attribution on standard DFN VAD.
   - $E21 - E20$: Impact of conservative overlap attribution on consensus VAD.
3. **Interaction Effect**:
   - $(E21 - E20) - (E01 - E00)$: Tests whether consensus VAD improves or degrades the effectiveness of overlap attribution. (Stage 5B.2 suggested consensus VAD provides cleaner boundary anchors for turn-alternation search).
4. **Statistical Significance Testing**:
   - 8 recordings (R01–R08).
   - Paired Wilcoxon signed-rank test ($n=8$).
   - 10,000-iteration clustered bootstrap for 95% confidence intervals on $\Delta\text{DER}$.
   - Macro-averages reported side-by-side with duration-weighted pooled averages.
